# Hermes

Stateless Bun + Hono bot: GitHub org webhooks and Dokploy deploy notifications → Campfire rooms. Deployed on Dokploy. `README.md` (Spanish) is the human-facing source of truth for events, env vars, and deploy steps.

- **Code changes** (event handlers, review bots, routing, message format) → `docs/architecture.md`.
- **Missing alerts** or other production debugging → `docs/operations.md`.
- **Review** of any diff, before committing → `CODING_STANDARDS.md`.
- **Commits** use Spanish Conventional Commits (`feat: publica ...`), matching `git log`.
